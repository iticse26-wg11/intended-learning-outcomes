# CS01

**Area:** Computer Science (CS) · **Sub-area:** Foundations of GenAI · **Topic:** Types of models (local vs API, chatbot vs coding agent)

> *At the end of the course, students should be able to* …
>
> **distinguish between different types of GenAI systems (e.g., web-based chatbots, coding assistants, local vs cloud-hosted models) and apply this knowledge to select an appropriate system for a given context.**

## Why it is included

Builds the judgement to pick the right kind of tool for a task by comparing capabilities, limitations and deployment (chatbot, coding assistant, local or cloud); licensing trade-offs are left to CS03.
