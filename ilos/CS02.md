# CS02

**Area:** Computer Science (CS) · **Sub-area:** Foundations of GenAI · **Topic:** GenAI Core Concepts

> *At the end of the course, students should be able to* …
>
> **explain operational GenAI concepts (e.g., tokens, context windows, probability distributions, and non-determinism) and use these concepts to interpret system behavior, output variability, and prompt sensitivity.**

## Why it is included

Gives students the vocabulary to explain why the same prompt yields different answers; without tokens, context windows, and sampling, variability looks like malfunction rather than design (MM01, CS04b).
